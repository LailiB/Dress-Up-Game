# CISC204-S26-Project3-Template
This project is a solo project for my Intro to Game Development course taken at the University of Delaware. The assignment goal was to create a game where the player can swap out at least 3 different parts of the scene to customize their own scene. In addition, one of these elements should be able to be further customized, whether that was with rotating, scaling, or changing the color. Then, the player's choices should be able to be saved as a preset, to be loaded if desired.
All of the assets in this project were drawn by myself in Clip Studio Paint. I drew everything in Godot's display scale in order to get a proper idea of how large the assets had to be. This included the arrows, which caused the first roadbump. The actual size of the arrows were the size of the whole display, even if there was empty space around them. So in order to get them working, I had to crop each arrow separately before reimporting them. A majority of the programming was done in office hours, I often needed help with continuing the work because I knew what I had to do and an idea of how to do it, I just needed help wtih executing it properly. 
During this project, I learned how to utilize for loops and if statements to track what options had been pressed, and what should occur at the end of an array. I found out about color pickers, and included them in the project to expand the customization. I also got familar with importing my own assets into Godot, utilizing sprite nodes. I pushed myself to ask for help when needed, instead of waiting or brushing the whole project off. 
What I would improve in this project would be the saving and loading sections. I would look further into developing the section further, because in truth, I gave up on trying to figure it out. If I had gotten more help, I would have a little more experience under my belt.
